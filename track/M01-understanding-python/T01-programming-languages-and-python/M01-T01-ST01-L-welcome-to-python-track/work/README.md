## Programming vs Python

### Question 1
What is programming?

**Answer:** Programming is the process of designing and writing a set of instructions that tell a computer how to perform a task or solve a problem.

---

### Question 2
What is a programming language?

**Answer:** A programming language is a formal set of rules, symbols, and vocabulary used by humans to communicate instructions to a computer.

---

### Question 3
Is Python the same as programming?

**Answer:** No. Programming is the broad concept of problem-solving and instructing computers, while Python is simply one specific language used to write those instructions.

---

### Question 4
What is syntax?

**Answer:** Syntax is the set of grammatical rules that defines how code must be structured and written for the computer to understand it.

---

### Question 5
Can the same algorithm be written in Python and Java?

**Answer:** Yes. An algorithm is language-independent logic, meaning the same step-by-step solution can be implemented in Python, Java, or any other programming language.

---

### Question 6
Which comes first: understanding the problem or writing Python syntax?

**Answer:** Understanding the problem comes first. You must analyze the problem and design the logic before writing the code using Python syntax.

---

### Question 7
What remains the same when one solution is written in different programming languages?

**Answer:** The underlying logic, problem-solving approach, and algorithm remain the same; only the syntax and language-specific features change.

---

### Question 8
Can someone know Python syntax but still struggle to solve problems?

**Answer:** Yes. Memorizing syntax is like knowing grammar, while problem-solving requires logical reasoning and algorithmic thinking, which are separate skills.
